# Anmol Digital Seva — GitHub Pages

## Publish
1. Extract the ZIP.
2. Upload **all files and folders** to a GitHub repository.
3. GitHub → Settings → Pages → Deploy from branch → `main` / root.
4. Open the generated GitHub Pages URL.

## Included
- Responsive mobile-first landing page
- Welcome poster + single large services poster
- Local PNG social icons
- WhatsApp Channel popup on first visit
- WhatsApp, Telegram, YouTube, Instagram and Channel links
- 8K master poster files are included under `assets/`
- Optimized WebP versions are used by the website for faster loading

## Note
The Facebook button is intentionally pointed to Facebook's home page because no specific Facebook profile/page URL was supplied.
